# Где задать вопрос и оставить фидбек?

[← К документации](README.md)

Проект в ранней стадии, и сейчас обратная связь полезнее, чем код: пока интерфейс не устоялся,
любую неудачную идею ещё можно поменять дёшево.

## GitHub Issues

Основной канал — [issues репозитория](https://github.com/yhgrwav/leettest/issues). Это
встроенный в GitHub трекер: любой человек с аккаунтом создаёт запись, она получает номер, её
видно всем, в ней можно переписываться и на неё можно ссылаться из коммитов.

Годится всё:

- **нашли баг** — что запускали, что ожидали, что получилось;
- **не хватает возможности** — лучше с описанием задачи, которую пытались решить, а не только
  предлагаемого решения;
- **непонятная документация или сообщение об ошибке** — это дефект, а не мелочь;
- **вопрос** — если ответ на него не нашёлся здесь, значит документация недоработана.

Заводить issue можно без всяких формальностей: подписывать [CLA](../../CLA.md) нужно только для
pull request'ов с кодом.

## Обсуждения

Для вопросов без конкретной задачи — раздел Discussions того же репозитория, если он включён.
Формат свободнее, чем в issues.

## Чего пока нет

Отдельного чата, рассылки и аккаунтов в соцсетях у проекта нет. Появятся — ссылки будут здесь.
