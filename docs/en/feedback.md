# Where do I ask a question or leave feedback?

[← Back to docs](README.md)

The project is early, and right now feedback is worth more than code: while the interface is
still unsettled, a bad idea is cheap to change.

## GitHub Issues

The main channel is [the repository's issues](https://github.com/yhgrwav/grpc-loadgen/issues).
Anyone with a GitHub account can open one; it gets a number, stays visible to everyone, supports
discussion and can be referenced from commits.

Anything is fair game:

- **a bug** — what you ran, what you expected, what happened;
- **a missing capability** — ideally with the problem you were trying to solve, not only the
  solution you have in mind;
- **confusing documentation or an unclear error message** — that is a defect, not a nitpick;
- **a question** — if the answer was not here, the documentation has a gap.

Opening an issue takes no ceremony: the [CLA](../../CLA.md) is only needed for pull requests with
code.

## Discussions

For open-ended questions there is the Discussions tab of the same repository, when enabled. The
format is looser than issues.

## What does not exist yet

The project has no chat, no mailing list and no social accounts. When it does, the links will be
here.
