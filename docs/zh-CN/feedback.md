# 在哪里提问和反馈？

[← 返回文档](README.md)

> 本译文可能落后于[俄文原文](../ru/feedback.md)。

项目尚处早期，此刻反馈比代码更有价值：在接口定型之前，纠正一个糟糕的想法成本很低。

## GitHub Issues

主要渠道是[仓库的 issues](https://github.com/yhgrwav/leettest/issues)。
任何拥有 GitHub 账号的人都可以创建：它会获得编号、对所有人可见、可在其中讨论，
也可以从提交中引用。

什么都可以提：

- **缺陷**——你运行了什么、预期是什么、实际发生了什么；
- **缺少的能力**——最好说明你想解决的问题，而不只是你设想的方案；
- **文档或错误提示不清楚**——这是缺陷，不是小题大做；
- **疑问**——如果这里没有答案，说明文档存在缺口。

创建 issue 不需要任何手续：只有提交代码的 pull request 才需要签署 [CLA](../../CLA.md)。

## 讨论区

没有具体目标的开放性问题，可以使用同一仓库的 Discussions（如已启用），形式比 issues 更宽松。

## 目前还没有的

项目目前没有聊天群、邮件列表和社交媒体账号。一旦有了，链接会出现在这里。
