# Начало работы

Восстановить состояние и назвать один следующий шаг. Кода на этом шаге нет.

## Что прочитать

Ровно два источника, больше ничего:

1. **`TASK.md`** — единственный файл состояния. Разделы «В работе», «Следующее», «Открытые
   вопросы», «Техдолг».
2. **Состояние репозитория** — одной командой:

   ```
   git status --short && git branch --show-current && git log --oneline -3
   ```

   Открытые PR и красный CI проверять только если ветка не `main` или в `TASK.md` висит
   незакрытый PR: `gh pr list --state open`, `gh run list --branch main --limit 3`.

Журналов сессий нет. Историю не раскапывать: всё, что важно сегодня, лежит в `TASK.md`. Если там
пусто, а в работе явно что-то было — сказать об этом, а не идти искать по гиту.

## Что доложить

Четыре строки, не больше:

- ветка и есть ли незакоммиченное;
- что осталось хвостом с прошлого раза;
- блокеры первыми: незакрытый вопрос к Егору, красный CI, PR без ревью;
- **один** следующий шаг — с него и предложить начать.

## Чего не делать

- Не пересказывать `TASK.md` целиком.
- Не начинать работу, пока Егор не подтвердил шаг.
- Не открывать `docs/decisions.md` и `CLAUDE.md` авансом: они читаются, когда задача их касается.
